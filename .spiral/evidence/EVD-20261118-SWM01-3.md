# Discovery and shared Docker verification

On 18 November 2026, the locked Rust test run passed all three tests. It covered
page title and relative link parsing, raster normalization, and rejection of
unsupported schemes, credentials, custom ports and local or special addresses.
Rust formatting and the locked debug build passed.

A standalone smoke test verified health, the configured CORS origin, loopback
rejection and live title and PNG discovery from Python.org, Wikipedia and web.dev.
The final Compose build on Docker 29.1.3 started both containers using the
sibling checkout without a Workbench path override. HTTP checks through port 4189
verified Workbench, Documents, Preferences, the Turtle manifest and the PDF
worker MIME type. The shared origin returned the expected titles and valid PNG
images for Python.org and Wikipedia. A loopback destination and a caller-supplied
method field were rejected.

This verifies the service and development stack. Launcher paste/drop,
per-identity provider selection and automatic tile enrichment await the Workbench
integration cycle. The service has a bounded in-memory icon cache. Local
cycle acceptance is pending.

The credential-free cross-origin update passed the locked Rust tests. The
Docker endpoint returned wildcard CORS preflight headers for two origins and
omitted credential permission. Chrome used the live service across localhost
and 127.0.0.1 and received title and icon metadata. On the same source, the
acceptance recheck passed rustfmt, Compose configuration and the locked Rust
tests.
