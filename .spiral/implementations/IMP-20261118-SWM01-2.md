# Rust discovery and shared development stack

CYC-20261118-SWM01-1 implements the metadata portion of the linked Workbench design. The Rust process performs bounded anonymous outbound reads and returns only a title and a reference to a normalized cached image. It checks the resolved destination again for each page, redirect, manifest and icon request. A configured exact origin can call the service directly.

The maintainer asked to keep development orchestration separate within the same repository and to give each service its own root. The Rust build is in shortcut-metadata/ and dev/ contains Compose and the Workbench build/proxy. Workbench can use the endpoint on its development origin. The existing Launcher does not yet invoke it.
