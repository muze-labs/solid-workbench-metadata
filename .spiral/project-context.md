# Solid Workbench metadata service

This independent Rust repository implements the [Workbench shortcut metadata design](https://github.com/muze-labs/solid-workbench/blob/ca356df/design/solid-workbench-launcher-links-and-widgets.md#automatic-shortcut-metadata). The service discovers public titles and icons. The Launcher owns user provider preferences, shortcut persistence and navigation. The integration branch is main. Evaluate outbound request restrictions and the response contract before acceptance. Compose runs the service and the existing Workbench build on one development origin.
